Analysis Report: Query Reduction in Django & Django REST Framework (DRF)

Executive Summary

This report covers common causes of excessive database queries, optimization techniques, indexing strategies, and best practices for improving Django and DRF performance.

1. Common Causes of Excessive Queries

  • N+1 query problem
  • Reverse relationship lookups
  • Nested serializers
  • SerializerMethodField database access
  • Repeated queryset evaluation

2. Query Reduction Techniques

TechniquePurpose
select_related()Reduce queries for ForeignKey and OneToOne relationships using SQL JOINs.
prefetch_related()Efficiently load ManyToMany and reverse ForeignKey relations.
Prefetch()Prefetch filtered/custom querysets.
only()/defer()Load only required columns.
values()/values_list()Avoid model instantiation overhead.
annotate()Perform aggregations in SQL instead of Python loops.
aggregate()Database-side calculations.
exists()Cheaper existence check than count() > 0.
bulk_create()/bulk_update()Reduce write queries.
update()/delete()Single SQL statement for mass operations.

3. DRF Optimizations

  • Optimize get_queryset() with select_related() and prefetch_related().
  • Avoid database queries inside SerializerMethodField.
  • Use annotate() for computed values.
  • Serialize querysets using many=True instead of looping.

4. Query Analysis Tools

  • Django Debug Toolbar
  • django-silk
  • connection.queries
  • QuerySet.explain()
  • EXPLAIN ANALYZE (PostgreSQL)

5. Database Indexing

What is an Index?

An index is a data structure that allows the database to locate rows efficiently without scanning the entire table.

Advantages

  • Faster WHERE filtering
  • Faster JOIN operations
  • Improved ORDER BY performance
  • Better scalability on large tables
  • Reduced query execution time

Disadvantages

  • Consumes additional disk space
  • Slower INSERT operations
  • Slower UPDATE operations on indexed columns
  • Slower DELETE operations
  • Maintenance overhead (VACUUM/REINDEX)
  • Too many indexes reduce write performance

Django Index Examples

class Employee(models.Model):
    department = models.CharField(max_length=50, db_index=True)

class Meta:
    indexes = [
        models.Index(fields=["department", "salary"])
    ]

6. Best Practices

  • Use select_related() for ForeignKey and OneToOne.
  • Use prefetch_related() for ManyToMany and reverse ForeignKey.
  • Index frequently filtered, joined, and ordered columns.
  • Avoid queries inside serializers.
  • Use annotate() instead of repeated count().
  • Use exists() instead of count() > 0.
  • Profile using Debug Toolbar and explain().
  • Cache expensive queries and API responses.
